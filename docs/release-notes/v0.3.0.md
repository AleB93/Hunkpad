# Hunkpad 0.3.0: Git worktrees, Claude, and search

Work on several branches at once with Git worktrees, let Claude help with
commits and reviews (through your own Claude Code), and find any file or line
in a repository.

## Download

| System | File |
| --- | --- |
| Windows 10/11 | `Hunkpad_0.3.0_x64-setup.exe` (or the `.msi`) |
| macOS, Apple Silicon | `Hunkpad_0.3.0_aarch64.dmg` |
| macOS, Intel | `Hunkpad_0.3.0_x64.dmg` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

You also need [Git](https://git-scm.com/downloads). The installers are not
code-signed yet: on Windows click **More info → Run anyway**; on macOS use
**System Settings → Privacy & Security → Open Anyway** the first time.

## What's new

- **Git worktrees.** The Branches tab lists a repository's worktrees: create one
  from a branch, tag or commit, then open, lock, move, remove or prune it. A
  repository's worktrees share its tab, and the **Worktree** bar under the tabs
  switches between them.
- **Worktree setup (⚙ Setup).** Each new worktree gets the local files Git does
  not track (such as `.env`) copied from the main folder, then a command runs
  there: `pnpm install` by default for a Node project. **✨ Suggest with Claude**
  fills the setup in from the repository's file names and manifests.
- **Scripts for every worktree.** A repository's scripts run in the worktree you
  are on, with `HUNKPAD_WORKTREE` and, with a base port, `PORT` set, so two dev
  servers do not collide.
- **Claude features** (optional, off by default), through your own Claude Code
  CLI: draft commit messages, organize changes into groups, review changes as
  comments, describe a branch for a pull request, explain a commit, and suggest
  merge-conflict resolutions. You see every request before it is sent; Kept
  local and secret-looking files are never sent.
- **Claude Code over MCP** (off by default): Claude Code sees what you are
  looking at in Hunkpad, organizes your changes, comments, works with
  worktrees and their setup, and stages or commits only after you approve.
- **Search**: Ctrl+P for files, Ctrl+Shift+F for text in all files, Ctrl+click
  on a word for where it is used.
- **Markdown preview** for `.md` files, a **Retro** theme next to Light and
  Dark, and bulk actions in the Comments tab.
