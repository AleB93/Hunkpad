# Hunkpad 0.2.0: now on macOS and Linux, and open source

Hunkpad is a lightweight Git client with VS Code-quality diffs: stage single
lines, review your own changes, and see every Git command before it runs.
This is the first public release, and the first one for **macOS and Linux**.

![Hunkpad](https://raw.githubusercontent.com/AleB93/Hunkpad/v0.2.0/docs/media/overview.png)

## Download

| System | File |
| --- | --- |
| Windows 10/11 | `Hunkpad_0.2.0_x64-setup.exe` (or the `.msi`) |
| macOS, Apple Silicon | `Hunkpad_0.2.0_aarch64.dmg` |
| macOS, Intel | `Hunkpad_0.2.0_x64.dmg` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

You also need [Git](https://git-scm.com/downloads). The installers are not
code-signed yet: on Windows click **More info → Run anyway**; on macOS use
**System Settings → Privacy & Security → Open Anyway** the first time.

## What's new

- **macOS and Linux support.** Shortcuts use ⌘ on macOS; scripts open in
  Terminal (macOS) or your terminal (Linux); Git hooks find tools such as node
  and Homebrew's Git even when the app is started from the Dock or a launcher.
- **Renamed from Diffpane to Hunkpad.** A repository's `.diffpane/` folder
  becomes `.hunkpad/` automatically the first time it is opened.
- **npm scripts in the Scripts row**: pick a `package.json` and one of its
  scripts, and run it with one click.
- **Copy for LLM** copies a `.md` file on macOS too (text on Linux).
- Settings now live in `settings.json` in the OS app-data folder.
- A strict Content Security Policy for the app's page.

## Fixes

- Line-level staging and the All changes overview now handle file names that
  contain a space.
