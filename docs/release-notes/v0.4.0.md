# Hunkpad 0.4.0: themes for everyone

Twenty-two new colour themes, one that changes with the seasons, and a fix for
stashing untracked files.

## Download

| System | File |
| --- | --- |
| Windows 10/11 | `Hunkpad_0.4.0_x64-setup.exe` (or the `.msi`) |
| macOS, Apple Silicon | `Hunkpad_0.4.0_aarch64.dmg` |
| macOS, Intel | `Hunkpad_0.4.0_x64.dmg` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

You also need [Git](https://git-scm.com/downloads). The installers are not
code-signed yet: on Windows click **More info → Run anyway**; on macOS use
**System Settings → Privacy & Security → Open Anyway** the first time.

## What's new

- **Themes**, in the Theme menu at the top right:
  - **Practical:** High contrast, Colour-blind safe (added lines in blue,
    removed in orange), Solarized light and dark, Nord, Sepia.
  - **Fun:** Neon, Terminal, Amber CRT, Vaporwave, Windows 95, Game Boy,
    Matrix, Blueprint (next to Retro).
  - **Seasonal & cultural:** Pride (LGBTQ+), Halal, Diwali, Lunar New Year,
    Christmas, Halloween, Sakura, Italia.

  Each comes with a matching code editor theme. The little animations (snow,
  petals, falling glyphs…) stay still when your system asks for reduced motion.
- **Auto (seasonal)** picks a seasonal theme on its dates (Diwali, Lunar New
  Year, Christmas, Halloween, Pride Month, Sakura, Festa della Repubblica) and
  follows your system the rest of the year.

## Fixes

- **Stash including untracked files** saved them but also left them in place.
  It now removes them, and so does checkout auto-stash. A stash's file list
  shows its untracked files, and Cancel in the stash message no longer stashes.

Full list: [CHANGELOG.md](https://github.com/AleB93/Hunkpad/blob/v0.4.0/CHANGELOG.md).
