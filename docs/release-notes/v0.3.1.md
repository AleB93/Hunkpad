# Hunkpad 0.3.1: a resizable side panel

A small update to 0.3.0: the side panel can now be made as wide as you need.

## Download

| System | File |
| --- | --- |
| Windows 10/11 | `Hunkpad_0.3.1_x64-setup.exe` (or the `.msi`) |
| macOS, Apple Silicon | `Hunkpad_0.3.1_aarch64.dmg` |
| macOS, Intel | `Hunkpad_0.3.1_x64.dmg` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

You also need [Git](https://git-scm.com/downloads). The installers are not
code-signed yet: on Windows click **More info → Run anyway**; on macOS use
**System Settings → Privacy & Security → Open Anyway** the first time.

## What's new

- **Resize the side panel** (Changes, History, Branches, Stashes, Comments) by
  dragging its right edge, from 220px up to 70% of the window. Double-click the
  edge to go back to the default width, or focus it and use the arrow keys.
  Hunkpad remembers the width.
